# Azkar Bot v14

بوت Discord مبني باستخدام Node.js وdiscord.js v14 لمشاركة الأذكار والأدعية.

## التشغيل

1. ثبّت Node.js 18 أو أحدث.
2. ثبّت التبعيات:

	```bash
	npm install
	```

3. افتح `.env` وأضف توكن البوت. قيمة `CLIENT_ID` موجودة مسبقًا.
4. شغّل البوت:

	```bash
	npm start
	```

## الأوامر

- `/azkar` يعرض ذكرًا عشوائيًا، مع خيار تحديد أذكار الصباح أو المساء أو الأذكار والأدعية العشوائية.
- `/set-channel channel:#channel` يحدد قناة نصية لإرسال ذكر عشوائي كل 30 دقيقة. يتطلب صلاحية إدارة الخادم.

يتم حفظ القناة المحددة محليًا في `config.json`، بينما توجد الأذكار المصنفة في `azkar.json`.
