# Azkar Bot v14

بوت Discord مبني باستخدام Node.js وdiscord.js v14 لمشاركة الأذكار والأدعية.

## التشغيل

1. ثبّت Node.js 18 أو أحدث.
2. ثبّت التبعيات:

	```bash
	npm install
	```

3. افتح `.env` وأضف توكن البوت. قيمة `CLIENT_ID` موجودة مسبقًا.
	فعّل أيضًا `Message Content Intent` من Discord Developer Portal لتعمل أوامر الموسيقى المباشرة.
4. شغّل البوت:

	```bash
	npm start
	```

## الأوامر

- `/azkar` يعرض ذكرًا عشوائيًا، مع خيار تحديد أذكار الصباح أو المساء أو الأذكار والأدعية العشوائية.
- `/set-channel channel:#channel` يحدد قناة نصية لإرسال ذكر عشوائي كل X دقيقة. يتطلب صلاحية Administrator.
- `/setime minutes:2` يغير فترة إرسال الأذكار فورًا. يتطلب صلاحية Administrator.
- في الرسائل داخل القناة المحددة بالثابت `CHANNEL_ID` فقط: `p` أو `play` للتشغيل، `s` أو `skip` أو `س` للتخطي، `stop` أو `وقف` أو `ايقاف` للإيقاف، `pause` للإيقاف المؤقت أو الاستئناف، و`seek` أو `قدم` أو `ق` للتقديم بالثواني.
- تظهر مع كل أغنية لوحة تحكم تفاعلية تتضمن الإيقاف المؤقت/التشغيل، التخطي، الإيقاف، التكرار، وقائمة فلاتر صوتية مثل Clarity وBassBoost و8D وKaraoke وNightcore وEcho.

يبقى البوت متصلًا بالروم الصوتي المحدد في `CHANNEL_ID` ولا يغادر عند فراغ الروم أو انتهاء قائمة التشغيل. يستمر خادم Express في الاستماع إلى `PORT` على Render.

يتم حفظ القناة المحددة محليًا في `config.json`، بينما توجد الأذكار المصنفة في `azkar.json`.
